Act only on a ready capsule for the current revision. If mandatory context overflows, stop mapped execution and report the measured size. After a correction, prepare again; old Evidence remains attached to its original revision.

Archive public tool input/result, native call locator, version and observed usage through the authenticated State Service or installed observation queue. Preserve the receipt's coverage: SDK callback stimuli are not model-generated turns. Do not read private reasoning or write canonical SQLite directly. Host tokens record observations; registered verifiers create Validation; canonical adoption follows the State contract.

Replay means reading observations or rebuilding permitted indexes. Retry a queued observation with its original event identity; never retry its tool/model action. Keep unknown outcomes or charges unresolved until authoritative reconciliation. Client titles and folders describe native organization and do not change semantic Affiliation.

This Skill provides workflow guidance. Host trust, tool admission, canonical ACLs, revision checks, leases and budget controls provide enforcement. Load only Task-relevant skills and tools; do not inject a complete ecosystem catalog into every round.
