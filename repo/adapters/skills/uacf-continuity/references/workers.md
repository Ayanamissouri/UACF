# Coding worker defaults

Use the registered `coding_worker_prepare` / `coding_worker_run` actions (MCP
`uacf_coding_worker_*`), then record the main-host actual diff/boundary/test audit.
Do not stop at installing this guidance. No secondary model configured means a
reminder at every new work start and the original main model; configured but
broken/unverified means registered DS. Keep the current source interpretation
reviewed before coding; see `docs/engineering/consistency-and-coding-workers.md`
in the UACF repository for schemas and enforcement limits.

Active resumed Tasks must inherit missing coding roles/egress/budget bindings
before dispatch, not only at initial enrollment. Owner action `coding_worker_bind`
can repair the exact current Task; preparation returns its resulting `task_ref`.
Existing account conflicts remain explicit and never borrow another account.
A configured worker's missing Task binding is a repairable integration gap, not
permission to silently abandon the default worker and write all chores on main.
Stopped/archived Tasks and existing bound setups are not bulk rewritten.

Preserve the existing main model and the configured native secondary model. If no secondary model is configured, remind at each new work start and retain the original main model. Otherwise use gpt-6-luna through the existing Codex subagent tool when the native setup is usable AND current five-hour remaining percent is at least 40 AND remaining percentage points divided by positive minutes until reset is at least 1. Default to DeepSeek through the existing registered Codex/DSH/Pi/UACF route and Task budget for low/unknown quota or broken/unverified configured setup. Never infer quota from an old screenshot.

Before delegating, fix the interfaces, complete relevant inputs/outputs, method, boundaries, write scope and acceptance checks. Keep the stable native context/prompt prefix and selected model; put changing source units last, reuse settled results, and inspect actual cache hit/miss tokens. Do not start a second independent conversation or direct API client to replace an existing native task. Do not claim cross-provider cache reuse.

The main model reviews candidate code, actual differences, boundary cases and relevant checks. Submodels cannot self-accept. Unknown request outcomes are reconciled, never automatically repeated through another provider. Default routing is not unlimited spending authorization; retain Task budget and registered executor checks.

This file supplies guidance; the registered coding-worker actions and delivery guards enforce their documented scope. File installation alone is not proof that an existing native chat loaded its tools/hooks.
