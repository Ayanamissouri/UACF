# Portable assets and adaptive capture contract

2026-10-07. Owner-only private derivation uses the existing authenticated State Service. New mutations require operation_id and the relevant Task/module revision. No canonical SQLite writes or provider request are made by these operations.

`portable_draft(card, source_refs, derivation_basis)` validates exact bilingual public fields and exact current local sources, saves an immutable public projection blob in a private Artifact and preserves private provenance. Duplicate slugs require explicit revision. `portable_revise(module_ref, card, source_refs, derivation_basis)` uses CAS and resets disclosure review. `portable_review(module_ref, basis, public_content_hash)` reviews one exact local snapshot; it never authorizes upload. `portable_links(module_ref)` resolves local private references. `portable_overview()` lists local modules. `portable_export(module_refs)` returns only reviewed current public projections, synthetic examples and limitations, with no original private references or raw source body. Sources changing makes export fail until revision and review.

No regex scanner guarantees complete de-identification. The current host must evaluate contextual privacy and conditions, and the human owner reviews the concrete package before publication. Reusable principle/context cards do not register executable guards. Actual finite guard descriptions must accurately describe already registered scope; they do not install enforcement elsewhere.

Tasks opt into bounded capsule lessons with `portable_lessons=true`. Keyword overlap locates at most three advisory projections, bounded to4000 bytes; it is not a semantic verdict or actual-use receipt. Optional projections yield to mandatory capsule contents.

`archive_trigger_check(task_id, task_revision, features)` receives bounded current-node annotations, not history. Owner annotations remain distinct from native delivery. Host callers require an existing event from that host and an exact Task mapping. Real `native-learning` Artifact timestamps provide capture cooldown; a requested capture never counts as a completed archive. Signals include explicit request, correction, requirement change, progress, owner satisfaction/completion, short daily work and a bounded cue. Tone alone and text volume do not establish failure. Explicit requests/critical corrections may bypass cooldown; normal changes coalesce. Overdue checks inspect metadata even during extraction cooldown. Model calls:0.

Only Tasks with `learning_capture_policy.mode=adaptive` opt into service metadata sweeps (at most64 per sweep, no paid extraction) and the adaptive native-work gate. Legacy frozen Tasks keep their old policy. Real Stop/turn-end/checkpoint sources still require durable public events; no fake callbacks or event replay. Account-wide cloud inactivity is unsupported without a real connector. Periodic evidence does not prove a source was generated, candidates were filled, a model used assets or a project passed acceptance.

UI controls draft/review/local links/export and current work annotations call these same contracts with authenticated browser envelopes. Logout clears local provenance and form buffers. Test expectations include draft export rejection, stale source rejection, private-reference exclusion, exact review hash, host event/mapping refusal, coalescing, overdue metadata, opt-in scanning and no provider call. Native automatic delivery remains a separate field acceptance requirement.

## Explicit same-conversation task continuation

An owner may supply previous_task_ref to learning_bind_host only with the exact previous Task head and current binding hash. The previous Task must be blocked, stopped or complete and have no unexpired executor lease. Running Tasks, stale heads, another mapping revision and host-only callers are refused. The previous Task is preserved; a Decision records both identities and the transition. This does not fabricate a native event or prove callback delivery. Empty authorities without executor leases remain supported.
