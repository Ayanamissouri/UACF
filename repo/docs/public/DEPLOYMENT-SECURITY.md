# 安装前安全与恢复 / Deployment security

安全预检先于启用远程服务。预检结果分为pass、remediation_required、not_applicable、unknown；unknown不能伪装成已修复。包不能在每台机无条件升级Java/Node或关闭防火墙。

1. 盘点系统、应用、服务与内嵌运行时，不读取浏览器资料、宿主密钥或订阅内容。保存版本、路径类别和运行实例状态，敏感拓扑只保留在本地。
2. 使用官方安全公告确定受影响组件和修复线。系统Node、Codex/其他应用内嵌Node、Go/Rust静态编译程序、Java、Python和.NET分别判断；升级一个全局解释器不证明其他组件修复。
3. 只在适用且兼容的范围执行升级。验证官方签名/hash、备份原配置、保留依赖锁和可恢复安装信息；大版本迁移在隔离候选先测试。审计零告警不证明没有漏洞。
4. 保留已有访问路径、管理服务和应用规则。启用/修改防火墙前备份规则，确认恢复方式；不得用长期关闭所有profile来解决连通性。
5. 重启受影响应用后同时核对磁盘与运行中版本。安装成功、待重启和实际加载分别记录；浏览器用户数据不属于可随意清理内容。
6. 新UACF环境使用官方hash锁依赖、单独authority及回环管理服务；已有资料使用既有内容寻址部署器、备份/恢复验证和受控切换。公网/远程暴露通过另行受控的transport provider，不直接把本机8766开放到公网。
7. 启用主机接入后先验证来源绑定、权限、拒绝路径和无模型canary，最后才运行已授权任务。未知执行结果先对账，不因网络超时重复运行。

本发行版没有携带第三方安装器或自动全局升级程序。需要离线包时，按组件许可、平台/架构、签名/hash及依赖关系独立制作物料清单。恢复配置备份和原始事件不是公开发行物。
