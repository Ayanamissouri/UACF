# UACF — Unified AI Continuity Fabric

2026-11-04

或者，你也可以把 UACF 理解为 **Understand, Act, Check, Finish**——理解、行动、核验、完成；也可以理解为 **Understand All Commands First**——先理解全部指令；而在工作以前，先做到 **Understand Actual Context First**——先理解真实情境。理解指令包括分清要求、追问、引用、比喻、夸张与逻辑转折，并结合背景、已有状态和历史纠正。

我们把反复出现的“说了却没被真正听进去”称为 **UNHEARD**；把资料尚未读取、却被当成已经阅读或验证的问题标为 **UNREAD**。前者提醒我们理解和承担当前责任，后者提醒我们如实区分未读、摘要、原文、检查与验收。

### 更直白地说：应对 UNHEARD，辨清 UNREAD

| 字母 | 失败类型 | 当前工作需要做到什么 |
|---|---|---|
| U | Unheeded instructions — 要求未被遵循 | 保留完整要求，让明确边界进入动作准入 |
| N | Neglected context — 情境被忽视 | 恢复背景、局部语境、已有状态与适用条件 |
| H | Hallucinated capability — 能力被想当然 | 分别核实能力、安装、加载和实际调用 |
| E | Excessive machinery — 机制与表达过量 | 用真实需要约束扩张、无用防御与冗长表达 |
| A | Assumed intent — 擅定意图 | 分清修辞与逻辑关系，区分用户要求和模型选择 |
| R | Repeated attempts without new grounds — 无新依据地重试 | 复用仍有效的证据，说明重试改变了什么 |
| D | Declared success without evidence — 无据宣布完成 | 对照逐项结果；一次操作成功不能替代任务完成 |

**UNREAD 是阅读状态，不是另一套缩写。** 未读原件、只读摘要、已读原文、经过检查和完成验收应分别记录。引用或检索到资料，不等于已经读过它；另一模型的意见，也不能自动成为已验证事实。

这些原则通过适用的来源合同、动作检查、历史召回和结果审查落实。自然语言理解仍需审查；有界控制和测试只证明各自覆盖的行为。

## English

You can also read UACF as **Understand, Act, Check, Finish**: understand the responsibility, act within its scope, check the result, and finish the work. Or read it as **Understand All Commands First**. Before starting work, **Understand Actual Context First**: distinguish requests, questions, quotations, metaphors, exaggeration and logical transitions, using the background, existing state and prior corrections.

We call recurring failures to actually heed the user **UNHEARD**. **UNREAD** marks material that has not been inspected but is treated as already read or validated. These terms make the problem visible; they are not claims that the underlying model has been made infallible.

#### In plain terms: address UNHEARD and make UNREAD visible

| Letter | Failure | Required response |
|---|---|---|
| U | Unheeded instructions | Preserve complete requirements and enforce explicit action boundaries |
| N | Neglected context | Recover background, local context, existing state and applicability |
| H | Hallucinated capability | Verify capability, installation, loading and actual calls separately |
| E | Excessive machinery | Tie extra mechanisms, defenses and prose to real needs |
| A | Assumed intent | Distinguish rhetoric and logical relations, user requirements and model choices |
| R | Repeated attempts without new grounds | Reuse valid evidence and identify what changed before retrying |
| D | Declared success without evidence | Trace each requested result; one successful action does not complete a task |

**UNREAD is a reading state, not another acronym.** Unread originals, inspected summaries, inspected originals, checked results and accepted deliverables are distinct. Retrieval or citation does not establish reading, and another model's opinion does not establish validation.

Applicable source contracts, action checks, historical recall and result reviews support these principles. Language interpretation still needs review; bounded tests establish only the behavior they cover.
