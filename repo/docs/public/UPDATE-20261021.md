## 发布与安全边界

- 只发布经过筛选的代码、合成测试、文档和许可证。原始对话、账号用量、私人报告、数据库、凭据、原生会话映射和本机配置不进入Git或附件。
- 公开包不包含Node、Java、浏览器、Python、模型或Pi第三方二进制。宿主内嵌运行时不会因系统Node升级而自动修复。
- 安全处置知识可作为新机器预检输入，但“这个版本在另一台机安装过”不是新机已修复证据。先盘点、核对适用公告与签名、保存恢复点，再升级并检查磁盘及运行中版本。
- 依赖使用已有hash锁和官方索引。第三方版本及公告会变化，部署当天复核；旧Python缺失或老旧解释器路径不能当作新机已验证。

## 与远程Fabric的关系

详见[当前架构](CURRENT-ARCHITECTURE.md)。UACF管辖任务、模型、预算、插件接入、配置所有权与归档；可选远程Fabric提供连接、受限动作和数据/endpoint运输。不合并私有出口实现进UACF，不再维护重复模型路由器或另一个资产压缩包格式。

## Upgrade notes

Download the complete release ZIP, verify SHA256SUMS, extract into a new directory and keep the existing data untouched. Read OPERATIONS.md before installation or migration. Do not overwrite a live store with a release ZIP or old backup. Configure each host explicitly; native loading and real calls must be checked separately. Current local deployment remains unchanged by GitHub publication.
